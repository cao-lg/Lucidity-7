# 🎓 学生论文评审工具包（半自动模式）

## 📋 工具说明

本工具包用于帮助教师完成学生论文评审工作（17篇论文）。

**核心理念**：自动化处理重复性操作，**人工负责内容审核**，确保每篇论文都得到认真评审。

---

## 🆕 半自动模式特点

### 智能分工

| 脚本自动完成 | 教师手动输入 |
|------------|------------|
| ✅ 打开论文 | ✅ 阅读论文内容 |
| ✅ 点击论文定稿 | ✅ 撰写针对性评语 |
| ✅ 截图保存预览 | ✅ 选择评定结果 |
| ✅ 填写评语 | ✅ 判断是否通过 |
| ✅ 提交表单 | |
| ✅ 返回论文列表 | |

### 工作流程

```
┌─────────────┐
│  打开论文   │  ← 脚本自动
├─────────────┤
│  论文定稿   │  ← 脚本自动
├─────────────┤
│  截图预览   │  ← 脚本自动
├─────────────┤
│ ⏸️ 暂停等待 │  ← 等待教师
│  阅读论文   │
│  撰写评语   │
├─────────────┤
│  填写评语   │  ← 脚本自动
│  提交表单   │  ← 脚本自动
├─────────────┤
│  返回列表   │  ← 脚本自动
├─────────────┤
│  继续下一篇 │  ← 循环
└─────────────┘
```

## 🚀 快速开始

### 首次使用（仅需一次）

**步骤 1：安装环境**

双击运行 **`install-agent-browser.bat`**

等待安装完成（约 2-3 分钟）

**步骤 2：配置 Chrome**

1. 关闭所有 Chrome 窗口
2. 双击 **`start-chrome-debug.bat`**
3. 在 Chrome 中登录教务系统
4. 打开论文评审页面

---

### 日常使用

**步骤 1：启动 Chrome**

双击 **`start-chrome-debug.bat`**

**步骤 2：开始评审**

1. 确保已登录并打开论文评审页面
2. 双击 **`review-all.bat`**
3. 按照提示操作

## 📝 使用流程详解

### 首次运行配置

第一次运行 `review-all.bat` 时，脚本会要求你配置页面元素：

```
请查看页面元素列表，告诉我：

📋 输入学生论文列表中第一个论文链接的元素编号: 5
📋 输入'论文定稿'按钮的元素编号: 3
📋 输入评语输入框的元素编号: 7
📋 输入提交/保存按钮的元素编号: 8
```

**如何找到元素编号？**

1. 脚本会显示页面上所有可交互元素
2. 每个元素前面有编号，如 `@e5`、`@e3`、`@e7`
3. 你只需要告诉脚本数字部分（如 `5`、`3`、`7`、`8`）

### 每篇论文的处理

```
[论文 1/17]
▶ 正在打开论文...
▶ 正在点击论文定稿...
📸 已保存截图：paper-1-20260508-143025.png

┌─────────────────────────────────────────┐
│  请阅读论文内容并填写评语                │
│  （截图已保存，可查看）                  │
└─────────────────────────────────────────┘

✏️ 请输入针对这篇论文的评语：你的论文研究方法科学，数据分析深入，文献综述全面。建议加强对XX方面的讨论。

✅ 请输入评定结果（优秀/良好/通过/需修改）：良好

▶ 正在填写评语...

◀ 返回论文列表...
```

### 评语格式示例

脚本会自动组合评语：

```
评定结果：良好

论文评语：你的论文研究方法科学，数据分析深入，文献综述全面。建议加强对XX方面的讨论。
```

## 🎯 评定选项

评审时，你需要输入评定结果：

| 评定结果 | 说明 |
|---------|------|
| **优秀** | 论文质量很高，达到优秀标准 |
| **良好** | 论文质量良好，符合要求 |
| **通过** | 论文基本符合要求，可以定稿 |
| **需修改** | 需要学生修改后再审 |

---

## 💡 评语撰写建议

### 优秀评语示例

```
该论文选题具有重要的理论价值和实践意义，研究方法科学合理，数据分析深入细致。
文献综述全面系统，涵盖了国内外相关研究的最新进展。
论文结构清晰，论证逻辑严密，结论可靠。
创新点明确，对XX问题提出了独到见解。
论文格式规范，符合学术规范。建议同意定稿。
```

### 良好评语示例

```
该论文选题合理，研究方法得当，数据分析较为完整。
论文结构合理，论证过程基本清晰，结论可信。
建议在以下方面进一步完善：
1. 加强XX部分的分析深度
2. 补充更多的实证数据
总体评价：该论文已达到本科毕业论文要求，建议同意定稿。
```

### 通过评语示例

```
该论文能够运用所学专业知识进行分析研究，基本掌握了论文写作规范。
论文内容基本完整，格式基本规范。
建议：
1. 进一步修改完善XX部分
2. 检查论文格式细节
总体评价：该论文基本符合要求，可以定稿。
```

### 需修改评语示例

```
该论文存在以下问题需要修改：
1. XX部分论述不够充分，需要补充
2. 参考文献格式不规范
3. 论文结构需要调整
请学生根据以上意见修改后再次提交审核。
```

## 🔧 故障排查

### 问题 1：agent-browser 未安装

```
❌ agent-browser 未安装
```

**解决**：运行 `install-agent-browser.bat`

---

### 问题 2：连接失败

```
❌ 连接失败！Chrome 未启动或端口未打开
```

**解决**：
1. 确保运行了 `start-chrome-debug.bat`
2. 检查 Chrome 是否已启动
3. 检查端口是否被占用

---

### 问题 3：元素引用错误

```
Error: Cannot find element @e5
```

**解决**：
1. 页面结构可能已变化
2. 关闭脚本，重新运行 `review-all.bat`
3. 重新获取最新的元素编号

---

### 问题 4：评语未填入

**解决**：
1. 检查评语输入框的元素编号是否正确
2. 可以直接在浏览器中手动填写

```

⏸️ 已暂停。你可以随时继续。
```

下次继续时，重新运行脚本即可（需要重新配置元素编号）。
